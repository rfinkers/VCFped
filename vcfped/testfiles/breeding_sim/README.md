# breeding_sim — plant-breeding validation cohort for VCFped

500 diploid samples, 3000 SNPs on 20 chromosomes (`ch01`…`ch20`, 150 each, ~0.7 cM apart), 81 families
(55 with more than one member, largest 36) up to 7 generations deep, with duplicates,
genotyping error, and a **fully known ground truth** (pedigree, phased haplotypes, true IBD).
Purpose: reconstruct the pedigrees *from scratch* with the VCFped pipeline and score the
result against the truth.

Everything here is generated by [`../generate_breeding_sim.py`](../generate_breeding_sim.py)
(seed 42; reproduced byte-for-byte under numpy 2.2 and 2.4). Re-generate or vary it with:

```bash
python vcfped/testfiles/generate_breeding_sim.py                      # this dataset
python vcfped/testfiles/generate_breeding_sim.py --seed 7 --out-dir /tmp/sim7
python vcfped/testfiles/generate_breeding_sim.py --snps-per-chr 50    # sparse: 1000 SNPs (see below)
```

Other knobs: `--n-samples`, `--n-duplicates`, `--error-rate`, `--missing-rate`,
`--n-bad-markers`, `--fst`, `--interference-nu`, `--min-ibd-cm`.
`pytest tests/test_generate_breeding_sim.py` checks the generator (21 tests, ~15 s).

## Running and scoring the pipeline

One script runs the pipeline stages from `CLAUDE.md` and scores the result against the truth:

```bash
utilities/run_validation_pipeline.sh -o runs/seed42 -j 10
```

Stages run in order (`pairs, purge, trios, filter, plink, beagle, refine, qc, score`), each logging to
`OUTDIR/logs/<stage>.log`, and each is skipped on rerun if already done (`--force` to redo,
`--stages a,b` to pick). Environment: `PYTHON`, `PLINK2`, and, to include phasing and IBD,
`BEAGLE_CMD="java -Xmx16g -jar beagle.jar"` and `HAPIBD_CMD="java -Xmx16g -jar hap-ibd.jar"`.
With those set, `--true-map` gives hap-IBD the true genetic map instead of the uniform synthetic
one, and `--hapibd-min-markers` (default 10) replaces hap-IBD's default of 100. If the plink2 in
use rejects `--mendel`, the runner reruns the generated script with that step replaced and the
Mendel scoring is skipped. The trio stage dominates the run time (about 40 minutes for the 500
samples with numba and 9 workers; its result writing is single-process, so more workers help little).

The scorer also works on its own, on whatever you have; every input switches on one section:

```bash
python utilities/score_against_truth.py --truth vcfped/testfiles/breeding_sim/breeding_sim \
    --samples breeding_sim.vcf.gz --pair step1_named.pair --purge-log purge.log \
    --trio step3_named.trio --fam step3_named_filtered_refined.fam --king step3_named_filtered_king_ext.kin0 \
    --ibd step3_named_filtered_ibd.ibd.gz --hbd step3_named_filtered_ibd.hbd.gz -o score
```

It prints a report and writes `score_score_report.txt`, `score_score_summary.json` (for comparing runs
or seeds) and `score_score_children.tsv` (one row per true child, with the outcome in each stage).
What it scores:

| Section | Input | Reports |
|---|---|---|
| Duplicate purge | `--purge-log` | removals that were true duplicates; **distinct individuals wrongly removed and lost** |
| Pairwise verdicts | `--pair` | MZ and parent-child calls vs truth; false MZ calls split by inbreeding |
| Trio stage | `--trio` | per truth kind (simple, inbred child, related parents, backcross): unique / ambiguous / wrong / inverted-only / missed / lost-by-purge; precision |
| Final pedigree | `--fam` | per truth kind: correct / partial / wrong / unassigned, spurious parents, what wrongly assigned parents truly are, per scenario |
| KING | `--king` | per true relationship: listed, in the correct degree band; extra pairs; PO vs full-sib IBS0 |
| Quality plants | `--genotype-quality`, `--mendel-individual`, `--mendel-artifacts` | planted low-call-rate, contaminated and high-error samples and bad markers found |
| IBD / HBD | `--ibd`, `--hbd` (repeatable) | coverage of true IBD per relationship, false pairs, hotspot block; per-sample HBD correlation |

Denominators use the original sample set, so anything the purge removes wrongly counts as a
miss. Test it on a subset of families with `--samples subset.vcf`.

## What is in the cohort

Anonymous IDs (`S0001`…`S0500`), shuffled column order — nothing leaks through names or
position. `breeding_sim_truth_samples.tsv` has the scenario tag and flags of every sample.

| Scenario (`SCENARIO`) | Models | Samples |
|---|---|---:|
| `trio`, `cross_pop_trio` | plain outbred trios, within / across founder populations | 31 |
| `fullsib`, `large_sibship` | full-sib families (2–12 sibs) with both parents genotyped | 58 |
| `fullsib_noparents` | sibships whose parents were lost: only kinship can find them | 15 |
| `one_parent_genotyped` | one parent lost: parent-offspring duos that are also full sibs | 7 |
| `halfsib`, `halfsib_shared_ungenotyped` | shared sire × several dams; shared parent lost | 29 |
| `multigen`, `random_multigen`, `multigen_gaps` | 3–5 generations; outcross / sib-mate / backcross / self; gaps = descendants not genotyped | 127 |
| `backcross` | F1 × recurrent parent, BC1…BC4 | 36 |
| `backcross_other`, `grandparent_cross` | F1 × the *other* parent; grandchild × grandparent; × aunt/uncle | 27 |
| `selfing` | selfing trees F1→F5 (bulk then single-seed descent) | 41 |
| `inbred_mating` | full-sib (F=¼), half-sib (⅛), first-cousin (1⁄16) mating | 35 |
| `hybrid` | F6 inbred lines → F1 → F2 (T2 `BB+BB=BB` is uninformative) | 29 |
| `cryptic_*` | genotyped individuals related through *lost* ancestors (cousins, sibs-as-founders, uncle × niece) | 17 |
| `role_switch` | one hermaphrodite as pollen parent in some crosses, seed parent in others | 14 |
| `missing_middle` | grandparents and grandchildren genotyped, parents lost | 8 |
| `unrelated` | negative controls | 26 |
| `duplicate` (flag `is_duplicate`) | 30 clone samples among the above (pairs and triplicates; half are clones of parents) | — |

`fullsib`/`halfsib`/`trio`/`random_multigen` also include small random families that fill the
cohort to 500; exact numbers per tag are in `_truth_samples.tsv`. 87 ancestors are
*not* genotyped (rows with `GENOTYPED=N`, IDs `U0001`…). 129 samples have F > 0.01 and 23 have
F > 0.9 (deeply selfed lines).

### Edge-case checklist

| Edge case | Where to look |
|---|---|
| Duplicates with independent genotyping noise (pairs, triplicates, clone of a parent / child / founder) | `_truth_duplicates.tsv`, flags `has_duplicate` / `is_duplicate` |
| Parent × own offspring (backcross), grandchild × grandparent: the two "parents" are 1st-degree relatives of each other | flag `parent_x_own_offspring`, `BC1`…`BC4` |
| Selfing (PAT == MAT) and deeply selfed near-identical lines that are **not** duplicates | flags `selfed`, `F2`…`F6`; `F_PED` |
| Sib / half-sib / cousin mating; inbred offspring whose kinship exceeds the class value | flag `parents_are_relatives`, `COMPLEX=Y` in `_truth_relationships.tsv` |
| Parent(s) not genotyped, or whole generation missing | flag `parent_ungenotyped`, `GENOTYPED=N` |
| Hermaphrodite role switching | flag `hub_both_roles` |
| Population structure (3 founder pools, Fst 0.04) and cross-pool hybrids | `_truth_snps.tsv` `POPn_FREQ`, flags `pop0/1/2` on founders |
| Poor-quality samples: 4 low call rate (10–25 %), 3 high error (3–5 %; two of them parents of 4–5 children each, so Mendelian-error repeat offenders), 2 contaminated | flags `low_callrate`, `high_error`, `contaminated` |
| 8 bad markers (15–30 % error, 4× missingness, low `QUAL`) | `_truth_snps.tsv` `BAD_MARKER` |
| Population-wide conserved block (IBD hotspot): first 40 % of `ch05`'s SNPs (3.5–53.6 cM), near-fixed in every founder | `_truth_conserved_regions.tsv` |

## Files

| File | Format | Notes |
|---|---|---|
| `breeding_sim.vcf` / `.vcf.gz` | VCF 4.2, `GT` only, unphased `0/1` | the input; same content twice (`vcfped.py` cannot read `.gz`) |
| `breeding_sim_truth.fam` | PLINK/BEAGLE `.fam` (`FID IID PAT MAT SEX PHENO`) | genotyped samples; `0` = parent not genotyped; clones carry their source's parents; SEX is `0` (hermaphrodite) |
| `breeding_sim_truth_phased.vcf.gz` | VCF, `0\|1` | error-free true haplotypes; hap 1 = paternal gamete (founders arbitrary) |

| `breeding_sim_truth_ibd.ibd.gz` | hap-IBD, 8 tab columns | true pedigree-IBD segments ≥ 2 cM; col 8 is cM length (loaded as `lod` by the project's scripts, as for real hap-IBD output) |

| `breeding_sim_truth_relationships.tsv` | TSV | every pair with pedigree kinship > 0 and kinship ≥ 0.0442 or a named relationship: `REL`, `PHI_PED` (expected, KING scale), `PHI_REALISED` (from haplotype labels), `NOMINAL_PHI`, `COMPLEX` |

## Scoring a reconstruction against the truth

`utilities/score_against_truth.py` does all of this (see above); the rules it follows:

* **Compare parent sets, not slots.** Which hermaphrodite is `PAT` vs `MAT` is a coin flip per
  cross, and vcfped's trio output is unordered.
* **Duplicates are interchangeable.** If X has a clone X′, either is a correct parent of X's
  children; use `_truth_duplicates.tsv` as equivalence classes.
* **Missing parents mean "no trio".** Children with a `0` parent in the truth `.fam` should not
  receive a genotyped parent pair; their sibs should show up as `full_sib` /`half_sib` in
  `_truth_relationships.tsv`. Selfed children (PAT == MAT) cannot appear as vcfped trios.
* **Report backcross trios separately** (flag `parent_x_own_offspring`): the logic that rejects
  co-parents that look parent-offspring to each other (`parents_are_compatible`) is exactly
  what these trios exercise.
* **Use `PHI_REALISED` to judge kinship accuracy**, not `PHI_PED`: realised sharing varies
  around the expectation. Pairs with `COMPLEX=Y` exceed their class value because of
  inbreeding / multiple paths; KING-robust does not reproduce that inflation (see below).
* **Truth IBD is pedigree IBD.** Founder haplotypes are independent, so unrelated pairs have no
  truth IBD although they share alleles by state; hap-IBD may still report short chance
  segments, and will report the planted `ch05` block between nearly all pairs.

## What the data look like to the standard tools

Measured with PLINK2 v2.00a5.9 using the project's QC filters (`--geno 0.05 --maf 0.01
--hwe 1e-10`, then `--indep-pairwise 50 10 0.2`): 2931 of 3000 SNPs pass QC (6 fail `--geno`, 25
`--hwe`, 38 `--maf`) and 2928 survive LD pruning; `--make-king-table --king-table-filter 0.044`
then lists 1 613 pairs.

| Pedigree relationship (simple, non-inbred pairs) | n | listed by KING ≥ 0.044 | median KING |
|---|---:|---:|---:|
| duplicate | 24 | 100 % | 0.50 |
| parent-offspring | 359 | 100 % | 0.24 (IBS0 median 0.001) |
| full sib | 232 | 100 % | 0.25 (IBS0 median 0.020) |
| half sib | 64 | 100 % | 0.13 |
| grandparent | 148 | 70 % | 0.11 |
| avuncular | 129 | 71 % | 0.12 |
| first cousin | 56 | 66 % | 0.07 |

* Parent-offspring and full sibs are cleanly separated by IBS0 (95th percentile of PO 0.002,
  5th percentile of FS 0.013).
* 2nd-degree classes are only ~70 % recovered; for grandparents, 39 of the 44 missing pairs involve
  a partially inbred member (F ≥ 0.125). Pairs involving inbred individuals are systematically
  *under*-estimated by KING-robust (e.g. full sibs with `COMPLEX=Y`: median KING 0.16 vs ~0.45
  expected).
* 254 of the 124 750 pairs that are not in the truth relationships table appear in KING's table, all at
  0.044–0.088; 252 of them share no true IBD at all (structure among the three founder pools plus
  sampling noise), 2 are distant relatives. Lower `--fst` (e.g. `--fst 0`) for a cleaner background.

### vcfped's own pairwise stage

`vcfped_optimized --no-trio --no-gender` with default thresholds, scored against the truth. One
run on one seed: orientation, not a benchmark.

* All 32 true duplicate pairs are called `MZ twins`.
* 350 of 359 simple parent-offspring pairs are called `Parent-child` (189 of 206 pairs involving
  an inbred individual); none of the 232 simple full-sib pairs is mistaken for parent-offspring.
* **Over-calling:** 157 pairs with no duplicate or close relationship are called `MZ twins` — 147 of
  them between two deeply selfed lines (F > 0.9), i.e. 147 of the 253 possible pairs of such
  lines. This is the inbreeding-induced allele-sharing inflation the real cohort shows (see
  `--confirmed-duplicates` in `CLAUDE.md`), reproduced here on purpose. A further 17 selfed
  children of inbred parents are also called `MZ twins` with their parent.
* `Parent-child` also fires for 43 `other`, 24 inbred `grandparent` and 7 inbred `avuncular` pairs.

### vcfped's trio stage

Both engines require at least 100 informative sites per trio (`AA+BB` sites where the parents are
opposite homozygotes: `checkTriple` in `vcfped.py`, `t1_total >= 100` in `vcfped_optimized.py`) and
otherwise return `na`. That floor is why the default is 3000 SNPs: a true outbred trio has a
median of 252 such sites here (5th percentile 219). With 1000 SNPs (`--snps-per-chr 50`) the median
is 86 and vcfped calls almost none.

Measured on a 139-sample / 17-family subset (the full 500-sample trio stage did not finish in
30+ minutes without numba), true trios scored as `Regular trio` (clone-equivalent parents accepted):

| SNPs | simple trios (n=52) | backcross / parent × own offspring (n=6) | parents related (n=6) | inbred child (n=5) |
|---:|---:|---:|---:|---:|
| 1000 (`--snps-per-chr 50`) | 4 | 0 | 0 | 0 |
| 2000 (`--snps-per-chr 100`) | 52 (3 with extra candidate pairs) | 0 | 0 | 1 |
| 3000 (default) | 52 (4 with extra candidate pairs) | 0 | 0 | 2 |

The backcross and related-parent trios are never `Regular trio`, and the reason is structural, not
a matter of marker count. Test 1 counts sites where the two parents are opposite homozygotes, and
the two parents of a backcross child are themselves parent and offspring, so there are almost none
(median over the 34 backcross trios: 5, maximum 17; related parents: median 34, maximum 96; simple
trios: median 252, minimum 205). Against the floor of 100 they produce no trio row at all, not even
an inverted one. If these relationships are to be found, KING and IBD have to find them
(`refine_pedigree.py --include-inverted`, `extend_pedigree.py`); the scorer shows whether they do.
One seed, one subset.

## Limitations

* **Marker density.** 150 SNPs per chromosome (~0.7 cM apart). hap-IBD's default `min-markers=100`
  asks for 100 markers in a seed segment, about 67 cM here (most of a chromosome), so lower it
  (e.g. 10) or you will only see the longest segments. BEAGLE has little LD to phase with (founders
  have none). BEAGLE and hap-IBD were not run when this dataset was produced; only the truth files
  exist for them.
* **No LD among founders**, SNPs independent within each founder pool (as in sequoia's
  `SimGeno`, whose documentation warns this gives an *optimistic* picture of reconstruction
  performance). Linkage within families is real (true meiosis); founder LD is not.
* One seed, one pedigree. Run `--seed` variations before drawing conclusions from a single
  number.

## Design rationale and sources

* **Simulate meiosis along a genetic map** instead of drawing genotypes per locus — the approach of
  [ped-sim](https://github.com/williamslab/ped-sim) (Caballero et al. 2019, *PLoS Genet*; interference
  narrows the spread of IBD sharing among relatives) and
  [PedigreeSim](https://www.wur.nl/en/show/Software-PedigreeSim.htm) (Voorrips & Maliepaard 2012;
  diploid/polyploid pedigreed populations, with/without chiasma interference). Crossovers follow a gamma renewal process
  (`--interference-nu`, 1 = Haldane), ~1 per Morgan per gamete.
* **Founder-haplotype labels** make true IBD/HBD and realised kinship exact (ped-sim likewise
  emits true IBD segments).
* **Kinship classes** use KING's scale and thresholds (0.354 / 0.177 / 0.0884 / 0.0442 for
  duplicate / 1st / 2nd / 3rd degree; Manichaikul et al. 2010,
  [Bioinformatics 26:2867](https://academic.oup.com/bioinformatics/article/26/22/2867/228512)).
* **Realistic noise and missing parents**: genotyping error and missingness plus a
  large share of non-genotyped parents, as in the benchmarks of Huisman 2017
  ([sequoia, *Mol Ecol Resour*](https://pmc.ncbi.nlm.nih.gov/articles/PMC6849609/);
  sequoia's `EstConf` simulates 400 SNPs, 0.1 % error and 40 % non-genotyped parents by default).
* **Mendelian-inconsistency screening** of pedigree-vs-SNP data was validated in the literature
  by permuting pedigree against genotype data to create known errors (Calus et al. 2011,
  [PMC3377921](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC3377921/)); the high-error and
  contaminated samples and bad markers here serve the same purpose for
  `analyze_mendel_errors.py` / `check_genotype_quality.py`.
* **Plant-specific**: hermaphrodite role switching, selfing series, backcross (recurrent-parent)
  series, hybrids of inbred lines, pericentromeric crossover suppression, 70–130 cM per
  chromosome (typical crop map lengths of ~60–170 cM).
